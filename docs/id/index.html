Jadwal sholat

Huzur Vakti menyatukan jadwal sholat dengan notifikasi adzan, kompas arah kiblat, imsakiyah Ramadhan (waktu sahur dan berbuka), kalender Hijriah, Al-Qur'an, penghitung tasbih, dan pencatat salat qada dalam satu aplikasi — tanpa iklan dan tanpa akun.

Waktu dihitung di ponsel Anda sendiri, dengan metode lembaga keagamaan negara Anda (Diyanet untuk Türkiye, JAKIM untuk Malaysia, Karachi untuk Pakistan, dan sejenisnya). Tersedia 90 negara dan 600 kota. Tidak perlu internet: aplikasi berjalan sepenuhnya secara offline.
